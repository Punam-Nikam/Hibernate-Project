# Hibernate-Project
This project demonstrates CRUD operations using Hibernate ORM, Java, and PostgreSQL through a Student Management System. 

# Hibernate with PostgreSQL - CRUD OPERATIONS

## 📌 What is Hibernate?

Hibernate is an **ORM (Object Relational Mapping) framework** for Java that connects Java applications with databases.

It allows developers to work with **Java objects instead of writing SQL queries**.

---

## 🧠 Why Hibernate?

- Removes need for complex SQL
- Converts Java objects → database tables
- Simplifies database operations
- Reduces JDBC boilerplate code

---

## 🔄 What is ORM?

ORM maps:
- Java Class → Database Table  
- Java Object → Table Row  

---

## ⚙️ Core Components

- **SessionFactory** → Creates sessions (heavy object)
- **Session** → Used to perform database operations
- **Transaction** → Ensures safe commit/rollback of data

---

## 🔄 CRUD Operations

- **Create** → Insert data
- **Read** → Fetch data
- **Update** → Modify data
- **Delete** → Remove data

---

## 🗄️ PostgreSQL Role

PostgreSQL is the database where data is stored, and Hibernate acts as a bridge between Java and PostgreSQL.

---

## 📌 Summary

Hibernate simplifies database interaction by mapping Java objects to database tables and handling CRUD operations efficiently.
